# Changelog

All notable changes to this project are documented here.

## 0.2.0 - 2026-06-12

- Added drag-and-drop tab reordering inside each Container group.
- Added top-level Container picker for new tabs.
- Added strict `cookieStoreId` validation after Container tab creation.
- Added local status reporting for verified and failed tab creation.
- Prepared the extension as a maintainable GitHub and AMO project.

## 0.1.0 - 2026-06-12

- Added vertical tab sidebar.
- Added grouping by Firefox Container.
- Added collapsible Container groups.
- Added tab activation, close, middle-click close, filtering, and per-group new tabs.
